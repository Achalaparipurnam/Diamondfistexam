# Diamond First Exam English Grammar Workbook

This repository contains an editable manuscript, presentation-ready HTML source, supporting SVG diagrams, a validation report, and an A4 PDF shell for the workbook project.

## Contents
- `Diamond_First_Exam_English_Grammar_Workbook.html` — editable workbook source
- `Diamond_First_Exam_English_Grammar_Workbook.pdf` — generated A4 PDF shell file
- `source-content/` — manuscript content and original visual assets
- `README.md` — build and usage instructions
- `validation_report.md` — verification notes and counts

## Project status
The repository started empty. This package was created from scratch to satisfy the requested workbook deliverables as a self-contained publication source.
